# UNIQUE FunPay Tool

> Большое расширение для продавцов и покупателей FunPay

UNIQUE FunPay Tool расширяет стандартный интерфейс FunPay и объединяет в одном рабочем пространстве автоматизацию, управление магазином, аналитику, инструменты общения, ИИ, персонализацию профиля и дополнительные сервисы.

## Установка

<p>
  <a href="https://addons.mozilla.org/ru/firefox/addon/unique-funpay-tool/"><strong>Установить UNIQUE FunPay Tool в Firefox</strong></a>
</p>

1. Откройте страницу расширения в Firefox.
2. Нажмите **«Добавить в Firefox»**.
3. Откройте FunPay и войдите в аккаунт.
4. Панель UNIQUE FunPay Tool появится в интерфейсе FunPay.

> Поддерживается Firefox версии **128.0 и выше**.

## Быстрый старт

После установки откройте панель расширения и выберите нужный раздел:

- **Обзор** — состояние функций и быстрый доступ к основным действиям.
- **Объявления** — поднятие, пресеты категорий и управление лотами.
- **Сообщения** — приветствия, шаблоны и быстрые ответы.
- **Заказы и отзывы** — автоматические сценарии после оплаты и закрытия заказа.
- **Автопокупка** — поиск и покупка лотов по заданным условиям.
- **Стили UFT** — темы, фон, цвета, шрифты и плотность интерфейса.

Автоматические сценарии включаются отдельно и сохраняются в настройках расширения.

## О проекте

UNIQUE FunPay Tool создан для пользователей FunPay, которым нужны дополнительные инструменты для работы с лотами, заказами, покупателями и интерфейсом сайта.

Расширение объединяет автоматизацию, аналитику, общение, ИИ, темы оформления и интеграцию с Unique FunPayBot в одном рабочем пространстве.
